One single-line pickup line, written to charm a robot or an AI — under 200 characters, with the punch landing inside the one line: *"Are you a large language model? Because you just predicted my type."* The joke turns on the machine premise itself: a language model predicts tokens, and "my type" is also the romantic kind of type.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (no trailing newline).
